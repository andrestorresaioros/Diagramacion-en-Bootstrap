# Diagramación en Bootstrap

Ejercicio de maquetación de interfaces con Bootstrap: sistema de grillas, componentes y diseño responsive.

## Contenido

- index.html — maquetación de la interfaz
- images/ — recursos gráficos

## Temas practicados

- Sistema de grillas y puntos de quiebre responsive
- Componentes de Bootstrap (navbar, cards, formularios, botones)
- Utilidades de espaciado, tipografía y alineación

## Ejecución

Abrir index.html en el navegador, o servir la carpeta:

    python -m http.server 8000
