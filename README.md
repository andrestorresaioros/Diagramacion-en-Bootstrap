# Diagramación en Bootstrap — Portal de vehículos

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![Bootstrap](https://img.shields.io/badge/Bootstrap_5.3-7952B3?style=flat&logo=bootstrap&logoColor=white)
[![Demo](https://img.shields.io/badge/demo-en%20línea-2ea44f?style=flat)](https://andrestorresaioros.github.io/Diagramacion-en-Bootstrap/)

Maqueta de un portal de compra y venta de vehículos ("tucarro") construida únicamente con HTML y componentes de **Bootstrap 5.3**.

**Demo:** https://andrestorresaioros.github.io/Diagramacion-en-Bootstrap/

## Características

- Barra de navegación responsive (con menú colapsable) que incluye buscador y accesos de cuenta.
- Menú lateral de navegación por marca.
- Tabla responsive de los carros y camionetas más vendidos.
- Tarjetas de vehículos publicados con precio, año, kilometraje y ubicación.
- Diseño adaptable a móvil y escritorio mediante el sistema de grillas.

## Temas practicados

- Sistema de grillas y puntos de quiebre de Bootstrap.
- Componentes: navbar, nav, cards, tablas, botones y formularios.
- Utilidades de espaciado, tipografía y alineación.

## Estructura

```
.
├── index.html   # Maqueta completa (Bootstrap vía CDN)
└── Images/      # Imágenes de las publicaciones e icono del sitio
```

## Ejecución local

No requiere instalación. Abre `index.html` en el navegador o sirve la carpeta:

```bash
python -m http.server 8000
```
